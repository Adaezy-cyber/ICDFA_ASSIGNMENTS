## 1. Problematic Assignments

### Risk acceptance
CISO, CRO and IT could otherwise appear to share approval authority. The control is to separate security assessment, enterprise-risk challenge and formal risk acceptance.

### Security architecture
IT implements architecture, but implementation should not automatically equal approval. CISO is accountable for security architecture approval while IT is responsible for implementation.

### Regulatory notification
Security identifies the event, but Legal/Compliance provides the regulatory analysis. The authorised executive owns the final decision.

## 2. Implementation Guide

Managers should use the RACI **before work begins**.

1. Identify the activity.
2. Locate it in the RACI.
3. Confirm the Accountable role.
4. Confirm the Responsible team.
5. Identify Consulted stakeholders.
6. Define completion evidence.

During incidents, use the RACI without waiting for a full committee meeting. Operational teams act within authority while escalation follows the defined thresholds.

If two stakeholders claim the same decision, return to the RACI and delegation of authority, document the conflict and escalate if necessary. Repeated ambiguity should trigger a governance artefact update.

During assurance, compare actual decisions with the RACI. A RACI is effective only when observed behaviour matches the documented model.
