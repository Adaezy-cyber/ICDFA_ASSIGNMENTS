# Screenshots folder

**Status: empty on purpose.**

No screenshots are included because the lab environment could not be built (device storage was too limited to download Ubuntu Server 24.04 LTS). Screenshots would only be added from real tests on the analyst's own VMs. None are generated, edited or simulated.

When the lab is run, name each screenshot after its test ID from the `Evidence_Log` sheet (for example `T09-archive-403.png`) and reference it in the evidence log. Screenshots support the evidence; they do not replace saved command output and log extracts.
