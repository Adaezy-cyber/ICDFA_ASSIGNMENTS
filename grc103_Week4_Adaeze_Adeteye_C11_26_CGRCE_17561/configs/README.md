# Configurations

The `reference-design/` folder holds the configurations **as specified in the assignment brief**. They are the intended design for the lab.

**They were NOT captured from a running system and have NOT been deployed or tested**, because the Ubuntu Server VM could not be built (device storage limited). They must not be read as evidence that any control works.

After the lab is run, add the real configuration files copied from the VM (and compare them with these) in a new folder such as `configs/collected/`.
